# devcontainer.features
A collection of Dev Container Features managed by some Boy Scouts

## Features

| Feature | Description | Reference |
| ------- | ----------- | --------- |
| [aws-sam-cli](./src/aws-sam-cli/README.md) | Installs the AWS SAM CLI, auto-detecting OS, architecture and package manager | `ghcr.io/lodge104/devcontainer.features/aws-sam-cli:1` |

## Usage

```jsonc
{
    "image": "mcr.microsoft.com/devcontainers/base:ubuntu",
    "features": {
        "ghcr.io/lodge104/devcontainer.features/aws-sam-cli:1": {}
    }
}
```

## Development

Features live in `src/<feature>` with matching tests in `test/<feature>`.

```bash
# Test a feature against a base image
devcontainer features test -f aws-sam-cli --skip-scenarios -i debian:12 .

# Run a feature's scenarios
devcontainer features test -f aws-sam-cli --skip-autogenerated .
```
